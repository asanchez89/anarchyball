# AnarchyBall concept anchors

These images are visual direction references generated with the built-in OpenAI image generation tool on 2026-09-20. They are not production-ready spritesheets: frame spacing and registration must be rebuilt on the approved pixel grid before runtime use.

Reference image for both generations: `assets/art/world_0/frontier_forest/preview.png`. Its role was limited to palette, pixel density, outline and atmosphere.

## `anarchy_ball_compact_concept.png`

```text
Use case: stylized-concept
Asset type: production prototype pixel-art game character spritesheet with transparent background
Input images: Image 1 is a palette, pixel-density, outline, and atmosphere reference only; do not copy any character or scene composition from it.
Primary request: Create an original AnarchyBall protagonist sprite sheet for a 2D side-scrolling action platformer. The character is a simple expressive spherical ball with black-and-gold anarchist visual identity, two white eyes with black pupils, a small asymmetrical black flag-like accessory, and a compact defensive energy emitter mounted on a separate-looking side socket. No limbs and no humanoid anatomy.
Style/medium: crisp authentic retro pixel art, designed as if each animation cell were 24x32 source pixels and displayed at 3x nearest-neighbor scale; limited palette sampled in spirit from the purple, magenta, cyan and warm-orange Twilight Forest reference; chunky readable pixels, hard edges, no anti-aliasing.
Composition/framing: exactly 8 equal cells in one horizontal row, consistent baseline and centered registration. Frames 1-2 idle breathing/blink, frames 3-4 rolling movement, frames 5-6 jump rise/apex, frames 7-8 defensive fire/recoil. Keep the ball body and emblem consistent in every frame. Generous transparent separation between cells.
Constraints: genuinely transparent background; sprite sheet only; no grid lines, labels, text, scenery, floor, shadows outside each cell, watermark, gradients, blur, glow haze, smooth vector edges, extra objects, copied characters, hands, feet, arms or legs. Use only hard-edged pixel clusters. Keep silhouette readable at tiny game size.
```

## `anarchy_ball_detailed_concept.png`

```text

Asset type: high-detail prototype pixel-art game character spritesheet with transparent background
Input images: Image 1 is a palette, hard-pixel texture, outline, and atmosphere reference only; do not copy characters or scene composition.
Primary request: Create an original AnarchyBall protagonist sprite sheet for a 2D side-scrolling action platformer. Spherical character, no limbs, black and very dark purple body, warm-gold original anarchic emblem, two expressive white eyes, one minimal asymmetrical black pennant accessory, and a separate compact cyan-magenta defensive energy emitter attached on the side.
Style/medium: authentic hand-placed retro pixel art, designed as if each animation cell were 32x32 source pixels and displayed at 3x nearest-neighbor scale; slightly more emblem and facial detail than a 24x32 version; limited Twilight-inspired purple, magenta, cyan, warm-orange palette; chunky hard-edged pixels, no anti-aliasing.
Composition/framing: exactly 8 equal cells in one horizontal row with identical cell width, consistent bottom baseline and center registration. Frames 1-2 idle breathing/blink; frames 3-4 rolling movement; frames 5-6 jump rise/apex; frames 7-8 defensive fire/recoil. Preserve exact body size, emblem design, accessory and emitter placement across all frames. Clear transparent gutters between frames.
Constraints: genuinely transparent background; sprite sheet only; no grid, labels, text, scenery, ground, external shadows, watermark, gradients, blur, soft glow haze, vector-smooth curves, extra objects, copied characters, arms, hands, legs or feet. Both PNGs preserve an alpha channel. They are project-bound concept artifacts and remain separate from the purchased source packs.
```
